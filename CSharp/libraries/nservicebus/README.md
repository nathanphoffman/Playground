# NServiceBus

**Run:** `dotnet run`

NServiceBus is commercial. This demo uses the free learning transport and runs without a license, but prints a license warning. For real use you need a license (there is a free trial).

**Try next:** Try publishing an `IEvent` with two subscribers, retries (a handler that throws), and sagas for long-running workflows. Compare with MediatR (in-process) and `../../cloud/azure-servicebus`.
