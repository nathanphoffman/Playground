# gRPC (Node)

**Run:** `pnpm install`, then `pnpm server` in one terminal and `pnpm client` in another. Set `GRPC_ADDR=localhost:50051` to call the Go server instead (or `:50052` for C#).

**Try next:** Try generating real types with `@grpc/proto-loader`'s `proto-loader-gen-types`, streaming, and a gRPC-Web client for browsers.
