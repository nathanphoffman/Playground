# PrimeVue

**Run:** `pnpm install && pnpm dev`

PrimeVue is a component library with a very large set of components (tables, dropdowns, charts). Here it uses its Aura theme; components are imported one by one.

**Try next:** Try sorting and paging in `DataTable`, `Dialog`, `Toast`, and the unstyled mode with Tailwind. Compare with `../vuetify`.
