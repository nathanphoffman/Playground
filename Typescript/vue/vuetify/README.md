# Vuetify

**Run:** `pnpm install && pnpm dev`

Vuetify is a Material Design component library: ready-made buttons, forms, tables and layouts.

**Try next:** Try `v-data-table`, the theme (`createVuetify({ theme })`) with dark mode, and the grid (`v-row` / `v-col`). Compare with `../primevue` and Tailwind (`../../mithril`).
